## 2.1 Requisitos Funcionais
**RF01 – Cadastro de usuários:** O sistema deve permitir o cadastro e login de clientes e administradores de restaurantes.
**RF02 – Cadastro de restaurantes:** O administrador deve poder cadastrar e editar as informações do seu restaurante.
**RF03 – Cadastro de produtos:** O administrador deve poder adicionar, editar e remover produtos do cardápio.
**RF04 – Consulta de cardápios:** Os clientes devem poder visualizar os restaurantes e seus cardápios.
**RF05 – Carrinho de compras:** Os clientes devem poder adicionar produtos ao carrinho, inclusive de restaurantes diferentes.
**RF06 – Realização de pedidos:** O cliente deve poder finalizar a compra, escolhendo a forma de entrega e de pagamento.
**RF07 – Gerenciamento de pedidos:** O administrador deve poder acompanhar e atualizar o status dos pedidos, e o cliente deve poder visualizar essas atualizações.

## 2.2 Requisitos Não Funcionais
* O sistema deve proteger os dados dos usuários.
* O sistema deve apresentar bom desempenho durante o uso.
* A interface deve funcionar em celulares e computadores.
* O sistema deve ser fácil de usar.
* O sistema deve permanecer disponível para os usuários na maior parte do tempo.
